# 피부과 이벤트가 지도 (서울·경기)

각 병원 **홈페이지에 게시된 이벤트 가격**을 자동으로 모아 지도와 표로 보여주는 비공식 페이지입니다.

- 사이트: https://inh1095.github.io/clinic-price-map/
- 실제 결제가는 상담·부가세·옵션에 따라 달라집니다. 예약 전 반드시 해당 병원에 확인하세요.
- 법정 고지가(비급여 신고 상한)는 싣지 않습니다.
- 지도: Leaflet, 타일 © OpenStreetMap 기여자. 좌표는 도로명주소 자동 변환이라 건물 단위 오차가 있을 수 있습니다.
- 이 리포지터리에는 생성된 `index.html` 만 있습니다. 수집·빌드 코드와 원본 데이터는 비공개로 관리합니다.

병원 관계자분이 게시 중단을 원하시면 이슈로 알려주세요.
